# 교복 지도 수첩

아침 등굣길 교복 지도를 볼펜 체크 대신 휴대폰으로 처리하는 웹 앱입니다.
학생부 선생님과 선도부원이 각자 휴대폰에서 같은 링크를 열면 **하나의 명단과 적발 횟수를 실시간으로 함께** 보고 기록합니다.

**앱 주소** — https://claude.ai/code/artifact/36063497-a54d-4c0a-8f47-d087258db009

## 처음 준비 (선생님, 5분)

1. 위 링크를 열고 **명단** 탭으로 이동합니다.
2. `명단 일괄 등록` 칸에 전교생 명단을 붙여넣고 **명단에 반영**을 누릅니다.
   - 엑셀에서 `학번`·`이름` 두 열을 그대로 복사해 붙여넣어도 됩니다.
   - `CSV 파일 열기` 버튼으로 파일을 불러올 수도 있습니다.
   - 인식하는 형식
     ```
     10312 홍길동
     10313,김서연
     1,3,14,박도윤          ← 학년,반,번호,이름
     ```
   - 5자리 학번(`10312`)은 자동으로 **1학년 3반 12번**으로 해석됩니다.
3. `적발 사유 항목`을 학교 기준에 맞게 고칩니다. **첫 번째 항목이 `+1` 버튼의 기본 사유**입니다.
4. 앱 링크를 선도부원들에게 공유합니다. (페이지 우측 상단 공유 메뉴 → 링크 공유)

## 아침 지도할 때 (선도부원·선생님)

1. 처음 한 번만 오른쪽 위 버튼을 눌러 **기록자 이름**을 입력합니다. (휴대폰마다 따로 설정)
2. 검색창에 **이름 · 초성 · 학번** 중 아무거나 입력합니다.
   - `홍길동`, `ㅎㄱㄷ`, `10312` 모두 같은 학생을 찾습니다.
3. 학생 줄 오른쪽 **`+1`** 버튼을 누르면 즉시 적발 1회가 기록됩니다.
   - 아래에 뜨는 알림의 **취소**를 누르면 잘못 누른 기록을 바로 되돌립니다.
   - 사유를 골라 기록하거나 메모를 남기려면 **학생 이름을 눌러** 상세 화면을 엽니다.
4. 검색창을 비우면 **오늘 적발 현황**과 **최근 기록**이 보이고, 각 기록을 취소할 수 있습니다.

## 현황 확인·정리 (선생님)

- **현황** 탭에서 기간(오늘/이번 주/이번 달/전체)과 학급별로 걸러 봅니다.
- 누적 적발 순위, 사유별 집계를 확인합니다.
- **명단·횟수 CSV** / **적발기록 CSV**로 내보내면 엑셀에서 바로 열립니다(UTF-8 BOM).
- 학기가 바뀌면 **명단** 탭 → `적발 기록만 초기화`로 명단은 남기고 횟수만 0으로 되돌립니다.

## 알아두면 좋은 점

- **실시간 공유** — 한 사람이 기록하면 다른 사람 화면에도 곧바로 반영됩니다. 우측 상단 점이 초록색이면 공유 저장소에 연결된 상태입니다.
- **연결이 끊기면** 점이 주황색으로 바뀌고 안내 문구가 뜹니다. 이때 기록은 그 휴대폰에만 저장되니, 다시 연결된 뒤 확인해 주세요.
- **로그인이 필요합니다** — 공유 저장소를 쓰는 페이지라 링크를 받은 사람도 같은 조직의 Claude 계정으로 로그인해야 열립니다.
- **개인정보** — 학번·이름·적발 기록이 저장됩니다. 학교 개인정보 처리 방침에 따라 링크 공유 범위를 관리해 주세요. 졸업·전학 등으로 필요 없어진 자료는 `명단 전체 삭제`나 학생별 삭제로 지울 수 있습니다.
- **용량** — 학생 약 4,500명까지 등록할 수 있습니다.

## 소스

앱 전체가 `index.html` 한 파일입니다. 외부 라이브러리 없이 순수 HTML·CSS·JS로 되어 있고,
글꼴만 Google Fonts에서 불러옵니다.

- 저장: Artifact `db` 기능(학생 1명 = 문서 1개, 적발 이력은 학생 문서 안의 배열)
- 동시 기록 충돌 방지: 문서 단위 짧은 임대(`acquire`) 후 갱신
- 저장소를 쓸 수 없는 환경에서는 자동으로 `localStorage`로 전환

`index.html`을 고친 뒤 같은 파일 경로로 다시 게시하면 위 링크가 그대로 갱신됩니다.
