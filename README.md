# 교복 지도 수첩

아침 등굣길 교복 지도를 볼펜 체크 대신 휴대폰으로 처리하는 웹 앱입니다.
학생부 선생님과 선도부원이 각자 휴대폰에서 같은 주소를 열면 **하나의 명단과 적발 횟수를 함께** 보고 기록합니다.

검색창에 **이름 · 초성 · 학번** 중 아무거나 입력하면 학생이 뜨고, 오른쪽 **`+1`** 버튼 한 번으로 적발이 기록됩니다.

---

## 두 가지 버전

| | **A. 구글 스프레드시트 버전** (권장) | B. Artifact 버전 |
|---|---|---|
| 위치 | `gas/` | `index.html` |
| 준비물 | 구글 계정 1개 | 없음 (바로 사용) |
| 학생 접속 | **로그인 없이** 주소 + PIN | Claude 계정 로그인 필요 |
| 데이터 보관 | 선생님의 구글 스프레드시트 | Claude Artifact 저장소 |
| 선생님이 직접 열람·편집 | 스프레드시트에서 바로 ◎ | 앱 안에서만 |
| 엑셀 내보내기 | 스프레드시트 → 파일 → 다운로드 | 앱 안 CSV 내보내기 |

두 버전 모두 화면·검색·기록·현황 기능이 같습니다. 저장소만 다릅니다.

---

## A. 구글 스프레드시트 버전 (권장)

선도부원이 **로그인 없이** 쓸 수 있고, 모든 자료가 선생님의 구글 스프레드시트에 그대로 쌓입니다.

**설치 순서는 [`gas/설치_방법.md`](gas/설치_방법.md)에 그림 없이도 따라갈 수 있게 정리되어 있습니다.**
요약하면 이렇습니다.

1. 새 스프레드시트 → 확장 프로그램 → Apps Script
2. `gas/Code.gs` 와 `gas/Index.html` 붙여넣기
3. 스프레드시트 새로고침 → `교복 지도` 메뉴 → **① 초기 설정**
4. `설정` 시트에서 **기록PIN**(선도부원용)과 **관리PIN**(선생님용)을 정합니다
5. Apps Script → **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자)
6. 나온 주소를 선도부원에게 공유

### 시트 구성

| 시트 | 내용 |
|---|---|
| `명단` | 학번, 이름, 학년, 반, 번호, 누적횟수, 최근적발, 조정 |
| `기록` | 기록ID, 일시, 학번, 이름, 학년, 반, 사유, 메모, 기록자 — 적발 한 건이 한 줄 |

> `사유` 는 언제나 `교복 미착용`, `메모` 는 비어 있습니다.
> 두 칸은 예전 기록을 그대로 보존하려고 남겨둔 것입니다.
| `설정` | 기록PIN, 관리PIN, 학교명, 경고기준, 회부기준 |
| `면제` | 면제ID, 학번, 이름, 사유, 시작일, 종료일, 등록자, 등록일시 |
| `조정` | 조정ID, 일시, 학번, 이름, 이전횟수, 조정후횟수, 사유, 처리자, 메모 |

`누적횟수`는 앱이 자동으로 맞춰주므로 직접 고치지 않으셔도 됩니다. (`누적횟수 = 기록 건수 + 조정`)
`조정` 시트는 횟수를 손댈 때마다 한 줄씩 쌓이는 기록장입니다. 앱에서는 지우지 못하며, `적발 기록만 초기화` 때 함께 정리됩니다.
명단 시트는 평소처럼 정렬·필터·인쇄해서 쓰실 수 있습니다.

### 권한

| PIN | 보이는 화면 | 할 수 있는 일 |
|---|---|---|
| 기록 PIN | **지도 탭만** | 검색, 적발 기록 (**취소 불가**) |
| 관리 PIN | 지도 · 현황 · 명단 | 위 전부 + 기록 취소·삭제, 현황 확인, 명단 등록·삭제, 면제 기간 등록, 적발 횟수 조정, 선도위원회 기준 변경, 백업, 초기화 |

> 이전 버전을 쓰시던 시트에는 `설정` 시트에 **적발사유** 줄이 남아 있을 수 있습니다.
> 이제 쓰이지 않으니 그냥 두셔도 되고 지우셔도 됩니다.

선도부원 화면에는 하단에 **지도** 탭 하나만 보여서, 아침에 쓸 화면만 남습니다.
권한을 바꾸려면 오른쪽 위 **기록자 이름**을 눌러 `내 설정 → PIN 다시 입력` 을 쓰시면 됩니다.

두 PIN을 모두 비워두면 주소를 아는 누구나 관리자로 들어옵니다. 반드시 설정해 주세요.

## 쓰는 법 (두 버전 공통)

### 아침 지도할 때
1. 처음 한 번만 오른쪽 위 버튼을 눌러 **기록자 이름**을 입력합니다. (휴대폰마다 따로 설정)
   같은 자리에서 **화면 밝기**를 고르고, 현재 권한 확인과 **PIN 다시 입력**도 할 수 있습니다.
2. 검색창에 `홍길동` · `ㅎㄱㄷ` · `10312` 중 아무거나 입력합니다.
3. **`+1`** 을 누르면 즉시 기록됩니다.
4. 지난 이력을 보려면 **학생 이름**을 눌러 상세 화면을 엽니다.

적발 사유는 **교복 미착용** 한 가지로 통일되어 있어 고를 필요가 없습니다.
누를 것은 `+1` 하나뿐입니다.
5. 검색창을 비우면 **오늘 적발 현황**과 **최근 기록**이 보이고, 각 기록을 취소할 수 있습니다.

### 선도위원회 회부 경고

누적 적발이 기준에 가까워지면 검색 결과와 상세 화면에 경고가 뜹니다.

| 누적 | 표시 | 누적 칩 |
|---|---|---|
| 0회 | — | 옅은 회색 |
| 1 ~ 9회 | — | 회색 |
| **10 ~ 14회** | **회부까지 N회 남음** + 진행 막대 | 주황 |
| **15회 이상** | **선도위원회 회부 대상** | 진홍 |

- 경고가 떠도 `+1` 은 그대로 눌러 기록할 수 있습니다. 막지 않고 알려주기만 합니다.
- 기록 직후 알림에도 `누적 11회 · 회부까지 4회` 처럼 남은 횟수가 붙습니다.
- `현황` 탭의 **선도위원회 대상** 에서 해당 학생을 한 화면에 모아 봅니다. 회부 대상이 위로 올라옵니다.

**기준 횟수는 `명단` 탭 → 선도위원회 기준 에서 고칩니다.**
`경고 시작`(기본 10)과 `회부 기준`(기본 15) 두 칸이며, 저장하면 앱 전체에 바로 반영됩니다.
구글 스프레드시트 버전은 `설정` 시트의 `경고기준` · `회부기준` 칸에도 같은 값이 들어갑니다.

### 기록 취소는 선생님만

잘못 눌린 기록을 지우는 일은 **관리 PIN** 을 가진 선생님만 할 수 있습니다.

- 선도부원 화면에는 **취소 버튼이 아예 없습니다.** 기록 직후 뜨는 알림에도 취소가 없습니다.
- 선도부원이 잘못 눌렀다면 학생부 선생님께 말씀드려 지우시면 됩니다.
- 선생님은 **오늘 기록**을 최근 기록 목록이나 학생 상세 화면에서 한 번에 취소합니다.
- **지난 날짜 기록**을 지울 때는 날짜와 학생 이름을 보여주는 확인 창이 한 번 뜹니다.
- 화면뿐 아니라 **서버에서도 막습니다.** 기록 PIN으로는 취소 요청 자체가 거부됩니다.

### 화면 밝기

오른쪽 위 **기록자 이름** → `내 설정` → **화면 밝기** 에서 `밝게` 와 `어둡게` 중에 고릅니다.

- 누르면 **바로 바뀝니다.** 저장 버튼이 없습니다.
- 아직 고르지 않았으면 **휴대폰의 밝은/어두운 모드를 따라갑니다.** 설정 화면에는 지금 보이는 쪽이 켜져 있습니다.
- **쓰는 사람마다 따로** 정합니다. 선도부원이 각자 자기 휴대폰에서 고를 수 있고, 서로에게 영향을 주지 않습니다.
- 한 번 고르면 다음에 열 때도 그대로 유지됩니다.

### 하루 한 번만 기록됩니다

등교 시간과 점심 시간 두 번 지도하더라도, 한 학생은 **하루에 한 번만** 기록됩니다.

- 오늘 이미 체크된 학생은 검색하면 `+1` 버튼 대신 **✓ 오늘 아침 08:12 체크됨** 이라는 초록 안내가 뜹니다.
- 시간대는 자동으로 **아침**(12시 전) · **점심**(12~14시)으로 붙고, 그 외 시간에는 시각만 표시됩니다.
- 점심 지도 때 아침에 걸린 학생을 검색하면 바로 알아볼 수 있어 이중 체크가 생기지 않습니다.
- 기록을 **취소**하면 그 학생은 다시 체크할 수 있습니다.
- 화면뿐 아니라 **서버에서도 막습니다.** 두 선도부원이 같은 학생을 동시에 눌러도 한 건만 기록됩니다.

### 적발 횟수 조정

학생의 누적 횟수를 원하는 숫자로 맞춥니다. `명단` 탭 → **적발 횟수 조정** (관리 PIN 전용)

- 종이 기록을 앱으로 옮겨올 때, 선도위원회 이후 정리할 때 씁니다.
- **조정 사유는 반드시 골라야 합니다.** 버튼 네 개 중 하나를 누르세요.
  `종이 기록 이관` · `선도위원회 회부 반영` · `오기입 정정` · `기타`
- **`기타`** 를 고르면 아래에 **메모칸**이 열립니다. 이때는 메모도 필수입니다.
- **적발 이력은 지우지 않습니다.** 실제 기록 건수와 목표 숫자의 차이를 `조정` 값으로 남깁니다.
  누적 = 적발 이력 + 조정
- 학생을 고르면 현재 상태(`적발 이력 9회 · 조정 0회`)가 뜨고, 숫자를 입력하면 바뀔 결과와 회부까지 남은 횟수를 미리 보여줍니다.
- 상세 화면의 누적 횟수 옆에 `이력 9회 · 조정 +7회` 로 내역이 표시되어 나중에 봐도 왜 그 숫자인지 알 수 있습니다.
- 이후 `+1` 로 기록하거나 취소해도 조정값은 그대로 유지됩니다.
- 구글 스프레드시트 버전은 `명단` 시트의 **조정** 칸에 그대로 보입니다.
- 조정할 때마다 **누가 · 언제 · 누구를 · 몇 회에서 몇 회로 · 왜** 바꿨는지가 남습니다.
  앱에서는 폼 아래 **조정 기록** 에서, 스프레드시트에서는 **`조정` 시트** 에서 볼 수 있습니다.
  `사유` 칸에는 고른 버튼 이름이, `기타` 를 골랐을 때는 `메모` 칸에 적으신 내용이 들어갑니다.

### 학생 한 명의 이름·학번을 고치려면
학생 상세 화면에는 수정·삭제 기능이 없습니다.
구글 스프레드시트 버전은 **`명단` 시트에서 직접 고치시면** 됩니다. 엑셀처럼 편집하시면 앱에 바로 반영됩니다.
(학번을 바꾸실 때는 `기록` 시트의 해당 학번도 함께 고쳐주세요.)

### 명단 등록
`명단` 탭에서 한 줄에 한 명씩 붙여넣습니다. 아래 형식을 모두 인식합니다.

```
10312 홍길동
10313,김서연
1,3,14,박도윤          ← 학년,반,번호,이름
```

5자리 학번(`10312`)은 자동으로 **1학년 3반 12번**으로 해석됩니다.
엑셀에서 두 열을 그대로 복사해 붙여넣거나 CSV 파일을 불러올 수도 있습니다.

### 면제 기간 등록 (부상 등)

부상처럼 불가피한 사유로 **일정 기간** 지도에서 빼야 할 때 씁니다.
`명단` 탭 → **면제 기간 등록** 에서 네 가지만 채우면 됩니다.

| 칸 | 넣는 것 |
|---|---|
| 학생 | 이름이나 학번을 입력하면 후보가 뜹니다. 눌러서 선택하세요. |
| 면제 사유 | `발목 부상`, `깁스 착용` 처럼 짧게 |
| 시작일 | 기본값은 오늘 |
| 종료일 | 마지막 면제일 (그날까지 포함) |

- 면제 기간 중에는 검색해도 `+1` 버튼 대신 **면제 기간 발목 부상 ／ 교복지도 대상 아님** 안내와 기간이 표시되고, 기록 자체가 막힙니다.
- 아래 **면제 명단** 에서 `진행 중` · `예정` · `종료` 상태를 확인하고 삭제할 수 있습니다.
- 시작일이 아직 안 됐거나 종료일이 지난 면제는 지도를 막지 않습니다. 종료일이 지나면 별도 조치 없이 자동으로 풀립니다.
- 구글 스프레드시트 버전은 `면제` 시트에 그대로 쌓이므로 시트에서 직접 확인·수정하셔도 됩니다.

### 교복 지도 대상 제외 (운동부·위탁생)

이름 뒤 괄호 표기를 그대로 두면 앱이 알아서 지도 대상에서 빼줍니다.

| 표기 | 뜻 | 검색했을 때 |
|---|---|---|
| `홍길동(태)` | 운동부 — 태권도 | **운동부 태권도 ／ 교복지도 대상 아님** |
| `홍길동(배)` | 운동부 — 배드민턴 | **운동부 배드민턴 ／ 교복지도 대상 아님** |
| `홍길동(위)` | 위탁생 | **위탁생 ／ 교복지도 대상 아님** |

이쪽은 **기간이 없는 상시 제외**입니다. 일시적인 사유는 위의 면제 기간을 쓰세요.

- 검색 결과에서 **`+1` 버튼이 나오지 않고** 파란 안내 줄이 대신 표시됩니다.
- 이름은 괄호를 뗀 `홍길동` 으로 깔끔하게 보이고, 검색은 `홍길동`·`ㅎㄱㄷ`·학번 모두 됩니다.
- `홍길동 (태)` 처럼 띄어쓰기가 있어도, `[태]` 나 전각 괄호 `（태）` 여도 인식합니다.

- 지도 대상에서 제외된 학생은 기록 버튼이 나오지 않습니다.
- 명단 탭의 **지도 제외** 항목에서 몇 명이 인식됐는지 확인할 수 있습니다.
