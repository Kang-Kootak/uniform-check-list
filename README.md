# 교복 지도 수첩

아침 등굣길 교복 지도를 볼펜 체크 대신 휴대폰으로 처리하는 웹 앱입니다.
학생부 선생님과 선도부원이 각자 휴대폰에서 같은 주소를 열면 **하나의 명단과 적발 횟수를 함께** 보고 기록합니다.

검색창에 **이름 · 초성 · 학번** 중 아무거나 입력하면 학생이 뜨고, 오른쪽 **`+1`** 버튼 한 번으로 적발이 기록됩니다.

---

## 두 가지 버전

| | **A. 구글 스프레드시트 버전** (권장) | B. Artifact 버전 |
|---|---|---|
| 위치 | `gas/` | `index.html` |
| 준비물 | 구글 계정 1개 | 없음 (바로 사용) |
| 학생 접속 | **로그인 없이** 주소 + PIN | Claude 계정 로그인 필요 |
| 데이터 보관 | 선생님의 구글 스프레드시트 | Claude Artifact 저장소 |
| 선생님이 직접 열람·편집 | 스프레드시트에서 바로 ◎ | 앱 안에서만 |
| 엑셀 내보내기 | 스프레드시트 → 파일 → 다운로드 | 앱 안 CSV 내보내기 |

두 버전 모두 화면·검색·기록·현황 기능이 같습니다. 저장소만 다릅니다.

---

## A. 구글 스프레드시트 버전 (권장)

선도부원이 **로그인 없이** 쓸 수 있고, 모든 자료가 선생님의 구글 스프레드시트에 그대로 쌓입니다.

**설치 순서는 [`gas/설치_방법.md`](gas/설치_방법.md)에 그림 없이도 따라갈 수 있게 정리되어 있습니다.**
요약하면 이렇습니다.

1. 새 스프레드시트 → 확장 프로그램 → Apps Script
2. `gas/Code.gs` 와 `gas/Index.html` 붙여넣기
3. 스프레드시트 새로고침 → `교복 지도` 메뉴 → **① 초기 설정**
4. `설정` 시트에서 **기록PIN**(선도부원용)과 **관리PIN**(선생님용)을 정합니다
5. Apps Script → **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자)
6. 나온 주소를 선도부원에게 공유

### 시트 구성

| 시트 | 내용 |
|---|---|
| `명단` | 학번, 이름, 학년, 반, 번호, 누적횟수, 최근적발 |
| `기록` | 기록ID, 일시, 학번, 이름, 학년, 반, 사유, 메모, 기록자 — 적발 한 건이 한 줄 |
| `설정` | 기록PIN, 관리PIN, 적발사유, 학교명 |
| `면제` | 면제ID, 학번, 이름, 사유, 시작일, 종료일, 등록자, 등록일시 |

`누적횟수`는 앱이 자동으로 맞춰주므로 직접 고치지 않으셔도 됩니다.
명단 시트는 평소처럼 정렬·필터·인쇄해서 쓰실 수 있습니다.

### 권한

| PIN | 보이는 화면 | 할 수 있는 일 |
|---|---|---|
| 기록 PIN | **지도 탭만** | 검색, 적발 기록, 기록 취소 |
| 관리 PIN | 지도 · 현황 · 명단 | 위 전부 + 현황 확인, 명단 등록·수정·삭제, 면제 기간 등록, 백업, 초기화 |

선도부원 화면에는 하단에 **지도** 탭 하나만 보여서, 아침에 쓸 화면만 남습니다.
권한을 바꾸려면 오른쪽 위 **기록자 이름**을 눌러 `내 설정 → PIN 다시 입력` 을 쓰시면 됩니다.

두 PIN을 모두 비워두면 주소를 아는 누구나 관리자로 들어옵니다. 반드시 설정해 주세요.

## 쓰는 법 (두 버전 공통)

### 아침 지도할 때
1. 처음 한 번만 오른쪽 위 버튼을 눌러 **기록자 이름**을 입력합니다. (휴대폰마다 따로 설정)
   같은 자리에서 현재 권한을 확인하고 **PIN 다시 입력**도 할 수 있습니다.
2. 검색창에 `홍길동` · `ㅎㄱㄷ` · `10312` 중 아무거나 입력합니다.
3. **`+1`** 을 누르면 즉시 기록됩니다. 잘못 눌렀으면 아래 알림의 **취소**를 누르세요.
4. 사유를 골라 기록하거나 메모를 남기려면 **학생 이름**을 눌러 상세 화면을 엽니다.
5. 검색창을 비우면 **오늘 적발 현황**과 **최근 기록**이 보이고, 각 기록을 취소할 수 있습니다.

### 하루 한 번만 기록됩니다

등교 시간과 점심 시간 두 번 지도하더라도, 한 학생은 **하루에 한 번만** 기록됩니다.

- 오늘 이미 체크된 학생은 검색하면 `+1` 버튼 대신 **✓ 오늘 아침 08:12 체크됨** 이라는 초록 안내가 뜹니다.
- 시간대는 자동으로 **아침**(12시 전) · **점심**(12~14시)으로 붙고, 그 외 시간에는 시각만 표시됩니다.
- 점심 지도 때 아침에 걸린 학생을 검색하면 바로 알아볼 수 있어 이중 체크가 생기지 않습니다.
- 기록을 **취소**하면 그 학생은 다시 체크할 수 있습니다.
- 화면뿐 아니라 **서버에서도 막습니다.** 두 선도부원이 같은 학생을 동시에 눌러도 한 건만 기록됩니다.
- 꼭 한 번 더 기록해야 하면 학생 이름을 눌러 상세 화면의 **그래도 한 번 더 기록하기** 를 쓰시면 됩니다. 확인을 한 번 거칩니다.

### 명단 등록
`명단` 탭에서 한 줄에 한 명씩 붙여넣습니다. 아래 형식을 모두 인식합니다.

```
10312 홍길동
10313,김서연
1,3,14,박도윤          ← 학년,반,번호,이름
```

5자리 학번(`10312`)은 자동으로 **1학년 3반 12번**으로 해석됩니다.
엑셀에서 두 열을 그대로 복사해 붙여넣거나 CSV 파일을 불러올 수도 있습니다.

### 면제 기간 등록 (부상 등)

부상처럼 불가피한 사유로 **일정 기간** 지도에서 빼야 할 때 씁니다.
`명단` 탭 → **면제 기간 등록** 에서 네 가지만 채우면 됩니다.

| 칸 | 넣는 것 |
|---|---|
| 학생 | 이름이나 학번을 입력하면 후보가 뜹니다. 눌러서 선택하세요. |
| 면제 사유 | `발목 부상`, `깁스 착용` 처럼 짧게 |
| 시작일 | 기본값은 오늘 |
| 종료일 | 마지막 면제일 (그날까지 포함) |

- 면제 기간 중에는 검색해도 `+1` 버튼 대신 **면제 기간 발목 부상 ／ 교복지도 대상 아님** 안내와 기간이 표시됩니다.
- 아래 **면제 명단** 에서 `진행 중` · `예정` · `종료` 상태를 확인하고 삭제할 수 있습니다.
- 시작일이 아직 안 됐거나 종료일이 지난 면제는 지도를 막지 않습니다. 종료일이 지나면 별도 조치 없이 자동으로 풀립니다.
- 구글 스프레드시트 버전은 `면제` 시트에 그대로 쌓이므로 시트에서 직접 확인·수정하셔도 됩니다.

### 교복 지도 대상 제외 (운동부·위탁생)

이름 뒤 괄호 표기를 그대로 두면 앱이 알아서 지도 대상에서 빼줍니다.

| 표기 | 뜻 | 검색했을 때 |
|---|---|---|
| `홍길동(태)` | 운동부 — 태권도 | **운동부 태권도 ／ 교복지도 대상 아님** |
| `홍길동(배)` | 운동부 — 배드민턴 | **운동부 배드민턴 ／ 교복지도 대상 아님** |
| `홍길동(위)` | 위탁생 | **위탁생 ／ 교복지도 대상 아님** |

이쪽은 **기간이 없는 상시 제외**입니다. 일시적인 사유는 위의 면제 기간을 쓰세요.

- 검색 결과에서 **`+1` 버튼이 나오지 않고** 파란 안내 줄이 대신 표시됩니다.
- 이름은 괄호를 뗀 `홍길동` 으로 깔끔하게 보이고, 검색은 `홍길동`·`ㅎㄱㄷ`·학번 모두 됩니다.
- `홍길동 (태)` 처럼 띄어쓰기가 있어도, `[태]` 나 전각 괄호 `（태）` 여도 인식합니다.
- 명단에는 표기를 그대로 두시면 됩니다. 앱이 화면에서만 떼어내 보여주므로 종이 명단과 어긋나지 않습니다.
- 꼭 기록해야 할 사정이 있으면 학생 이름을 눌러 상세 화면에서 **그래도 적발 기록하기** 를 누르시면 됩니다. 한 번 더 확인을 거칩니다.
- 명단 탭의 **지도 제외** 항목에서 몇 명이 인식됐는지 확인할 수 있습니다.

### 현황 확인
`현황` 탭에서 기간(오늘/이번 주/이번 달/전체)과 학급으로 걸러 봅니다.

- **시간대별** — 아침(12시 전) · 점심(12~14시) · 그 외로 나눠 건수와 비중을 막대로 보여줍니다. 등교 지도와 점심 지도 중 어느 쪽에서 더 많이 걸리는지 한눈에 확인할 수 있습니다.
- **누적 적발 순위** — 상위 30명
- **사유별** — 어떤 항목이 많은지

### 적발 사유
`교복 미착용` · `생활복·사복 혼용` · `슬리퍼·크록스 착용` · `기타` 가 기본으로 들어 있습니다.
`+1` 은 첫 번째 항목인 **교복 미착용** 으로 기록되고, 학생 이름을 눌러 들어가면 다른 사유를 골라 기록할 수 있습니다.

바꾸시려면 구글 스프레드시트 버전은 `설정` 시트의 **적발사유** 칸을 쉼표로 구분해 고치시면 됩니다.
기본값으로 되돌릴 때는 `교복 지도` 메뉴 → **적발 사유 기본값으로 되돌리기** 를 쓰세요.

### 학기 정리
백업 사본을 먼저 만든 뒤 **적발 기록만 초기화** 를 실행하면 명단은 남고 횟수만 0이 됩니다.

## 개인정보

학번·이름·적발 이력은 개인정보입니다.

- 주소와 PIN은 필요한 사람에게만 공유하고, 학년이 바뀌면 PIN을 바꿔주세요.
- 보관 기간을 정해두고 지난 자료는 백업만 남기고 초기화하시길 권합니다.
- 외부 클라우드를 이용하므로 학교 정보부 담당 선생님께 한 번 확인받으시면 안전합니다.

## 만든 구조

외부 라이브러리 없이 순수 HTML·CSS·JS입니다. 글꼴만 Google Fonts에서 불러옵니다.

```
index.html              Artifact 버전 (Artifact db 저장소)
gas/Code.gs             Apps Script 서버 — 스프레드시트 읽기·쓰기, 동시 기록 잠금(LockService)
gas/Index.html          Apps Script 앱 화면 — 낙관적 UI, 20초 자동 동기화, 오프라인 캐시
gas/appsscript.json     프로젝트 설정 (시간대 Asia/Seoul)
gas/설치_방법.md         설치 순서와 자주 겪는 상황
```

두 버전 모두 화면과 저장소가 분리되어 있어, 다른 저장소로 옮기려면 서버 호출 부분만 바꾸면 됩니다.
