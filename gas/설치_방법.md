# 설치 방법 (구글 스프레드시트 + Apps Script)

준비물은 **구글 계정 하나**입니다. 처음 한 번만 15분 정도 걸리고, 그 뒤로는 손댈 일이 없습니다.
아래 순서를 그대로 따라가시면 됩니다. **컴퓨터에서** 진행하세요.

---

## 1단계 — 스프레드시트 만들기

1. 브라우저 주소창에 `sheets.new` 를 입력해 새 스프레드시트를 만듭니다.
2. 이름을 알아보기 쉽게 바꿉니다. 예: `2026 교복 지도`

## 2단계 — 코드 붙여넣기

3. 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭합니다. 새 탭이 열립니다.
4. 편집기에 있는 `function myFunction() {}` 를 **모두 지우고**, 이 저장소의 **`gas/Code.gs`** 내용을 전부 복사해 붙여넣습니다.
5. 왼쪽 `파일` 옆의 **＋** → **HTML** 을 누르고, 파일 이름을 **`Index`** 라고 입력합니다.
   > 이름이 정확히 `Index` 여야 합니다. (대문자 I, 확장자 `.html` 은 자동으로 붙습니다)
6. 새로 생긴 `Index.html` 의 내용을 **모두 지우고**, 이 저장소의 **`gas/Index.html`** 내용을 전부 복사해 붙여넣습니다.
7. **Ctrl+S** (맥은 ⌘+S) 로 저장합니다.

## 3단계 — 시트 만들기

8. 스프레드시트 탭으로 돌아가 **브라우저를 새로고침(F5)** 합니다.
9. 상단 메뉴에 **`교복 지도`** 가 새로 생깁니다. → **① 초기 설정 (시트 만들기)** 를 클릭합니다.
10. 처음 한 번은 구글이 권한을 묻습니다.
    - `권한 검토` → 본인 계정 선택
    - **“Google에서 확인하지 않은 앱입니다”** 화면이 나오면 → 왼쪽 아래 **`고급`** → **`(프로젝트 이름)(으)로 이동`** → **`허용`**
    - 선생님이 직접 만든 스크립트라서 나오는 안내입니다. 정상입니다.
11. `명단`, `기록`, `설정`, `면제` 네 개의 시트가 만들어집니다.

## 4단계 — PIN 정하기

12. **`설정`** 시트로 가서 두 칸을 채웁니다.

| 항목 | 값(예시) | 누구에게 |
|---|---|---|
| 기록PIN | `2026` | 선도부원·지도 담당 선생님 — **지도 탭만** 보이며 검색과 적발 기록만 |
| 관리PIN | `7788` | 학생부 선생님 — 지도·현황·명단 전부, 명단 편집·삭제까지 |

> 두 칸을 모두 비워두면 **주소를 아는 누구나 관리자로** 들어옵니다. 반드시 채워주세요.
> PIN을 바꾸면 최대 30초 뒤부터 적용됩니다.

## 5단계 — 앱으로 배포하기

13. 다시 Apps Script 탭으로 갑니다.
14. 오른쪽 위 **`배포`** → **`새 배포`** 를 클릭합니다.
15. 왼쪽 **톱니바퀴(⚙) → `웹 앱`** 을 선택하고, 아래처럼 설정합니다.
    - **설명**: `1차 배포` (아무거나)
    - **다음 사용자로 실행**: **나 (본인 이메일)**
    - **액세스 권한이 있는 사용자**: **모든 사용자**
16. **`배포`** 를 누르면 **웹 앱 URL** 이 나옵니다. 이 주소가 앱 주소입니다. 복사해 두세요.
    - 나중에 다시 볼 때는 스프레드시트의 **`교복 지도` → `② 앱 주소 보기`**

> ⚠️ **“모든 사용자” 선택지가 안 보인다면** 학교 구글(Workspace) 계정에서 관리자가 외부 공개를 막아둔 것입니다.
> 이때는 개인 지메일 계정으로 1~5단계를 다시 하시거나, 학교 정보 담당 선생님께 해제를 요청하세요.

## 6단계 — 명단 등록하고 공유하기

17. 앱 주소를 열고 **관리 PIN** 으로 들어갑니다.
18. **명단** 탭 → `명단 일괄 등록` 에 전교생 명단을 붙여넣고 **명단에 반영** 을 누릅니다.
    - 엑셀에서 `학번`·`이름` 두 열을 그대로 복사해 붙여넣어도 됩니다.
    - `10312` 같은 5자리 학번은 자동으로 **1학년 3반 12번** 으로 해석됩니다.
    - **운동부·위탁생**은 이름 뒤 괄호 표기를 그대로 두세요.
      `(태)` 태권도 · `(배)` 배드민턴 → **운동부**, `(위)` → **위탁생** 으로 인식해
      검색했을 때 `+1` 버튼 대신 **“교복지도 대상 아님”** 안내가 뜹니다.
19. 앱 주소와 **기록 PIN** 을 선도부원에게 안내합니다.
    - 휴대폰에서 열고 **홈 화면에 추가** 하면 앱처럼 씁니다.
    - 아이폰: 공유 버튼 → `홈 화면에 추가` / 안드로이드: ⋮ → `홈 화면에 추가`

## 자주 겪는 상황

**코드를 고쳤는데 앱에 반영이 안 돼요**
`배포 → 배포 관리 → 연필(✏) → 버전: 새 버전 → 배포` 를 하셔야 반영됩니다. 저장만으로는 바뀌지 않습니다.
(URL은 그대로 유지됩니다.)

**`교복 지도` 메뉴가 안 보여요**
Apps Script에서 저장(Ctrl+S)을 했는지 확인하고, 스프레드시트를 새로고침하세요.

**부상당한 학생을 한동안 지도에서 빼고 싶어요**
`명단` 탭 → **면제 기간 등록** 에서 학생을 찾아 선택하고, 사유와 시작일·종료일을 넣으면 됩니다.
그 기간에는 검색해도 `+1` 버튼 대신 면제 안내가 뜨고, 종료일이 지나면 자동으로 풀립니다.
`면제` 시트에서 직접 확인·수정하셔도 됩니다.

**이미 설치해서 쓰고 있는데 `면제` 시트가 없어요**
`Code.gs` 를 새 것으로 바꾸고 배포하면 면제를 처음 쓸 때 시트가 자동으로 만들어집니다.
초기 설정을 다시 실행하지 않으셔도 됩니다.

**선도부원 화면에 현황·명단 탭이 안 보여요**
기록 PIN으로 들어오면 하단에 **지도** 탭 하나만 보입니다. 정상입니다.
선생님이 확인하시려면 오른쪽 위 **기록자 이름**을 눌러 `PIN 다시 입력` 에서 관리 PIN을 넣으세요.

**운동부 학생인데 +1 버튼이 그대로 있어요**
명단의 이름 뒤에 `(태)`·`(배)`·`(위)` 표기가 있는지 확인하세요. 표기를 넣고 다시 등록하면 바로 반영됩니다.
명단 탭의 **지도 제외** 항목에서 몇 명이 인식됐는지 볼 수 있습니다.

**오늘 아침에 체크한 학생인데 점심에 또 눌러도 되나요**
안 됩니다. 하루 한 번만 기록되도록 되어 있어, 오늘 이미 체크된 학생은 검색하면
`+1` 버튼 대신 **“✓ 오늘 아침 08:12 체크됨”** 초록 안내가 뜹니다.
화면뿐 아니라 서버에서도 막으므로, 두 사람이 동시에 눌러도 한 건만 남습니다.
꼭 한 번 더 남겨야 하면 학생 이름을 눌러 **“그래도 한 번 더 기록하기”** 를 쓰세요.
기록을 취소하면 그 학생은 다시 체크할 수 있습니다.

**“명단에 없는 학번입니다” 라고 나와요**
그 학생이 `명단` 시트에 없습니다. 명단 탭에서 추가하시면 됩니다.

**다른 사람이 기록한 게 제 화면에 안 보여요**
약 20초마다 자동으로 반영됩니다. 급하면 오른쪽 위 점(●) 버튼을 누르면 즉시 새로고침됩니다.

**+1 을 눌렀는데 반응이 느려요**
화면에는 바로 반영되고 전송은 뒤에서 이루어집니다. 최근 기록에 `전송 중` 이라고 표시되는 동안이 전송 중입니다.
전송이 실패하면 화면도 원래대로 되돌리고 안내가 뜹니다.

**학기가 끝나서 정리하고 싶어요**
`교복 지도 → 오늘 자료 백업 사본 만들기` 로 사본을 만든 뒤,
`교복 지도 → 적발 기록만 초기화` (또는 앱의 명단 탭에서) 를 실행하세요. 명단은 남고 횟수만 0이 됩니다.

**사용량 한도가 걱정돼요**
구글 무료 계정 기준 스크립트 실행 시간이 하루 90분입니다. 아침 지도(20분, 10명 사용) 기준으로 하루 몇 분 수준이라 여유롭습니다.

## 개인정보 관련 안내

- 학번·이름·적발 이력은 **선생님의 구글 드라이브**에 저장됩니다.
- 앱 주소를 아는 사람 중 **PIN을 아는 사람만** 자료를 볼 수 있습니다. PIN은 꼭 설정하고, 학년이 바뀌면 바꿔주세요.
- 학교 개인정보 처리 방침에 따라 보관 기간을 정하고, 지난 자료는 백업 사본만 남기고 초기화하시길 권합니다.
- 외부 클라우드(구글) 이용에 해당하므로, 학교 정보부 담당 선생님께 한 번 확인받으시면 안전합니다.

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `gas/Code.gs` | 서버 코드. 스프레드시트를 읽고 쓰며, 동시에 기록해도 유실되지 않도록 잠금 처리를 합니다. 하루 한 번 원칙과 면제 기간도 여기서 다룹니다. |
| `gas/Index.html` | 휴대폰에서 보이는 화면 전체 (검색·기록·현황·명단). |
| `gas/appsscript.json` | 프로젝트 설정. 시간대(서울)와 배포 방식이 들어 있습니다. 선택 사항이며, Apps Script의 `프로젝트 설정 → 매니페스트 파일 표시`를 켜면 편집할 수 있습니다. |
