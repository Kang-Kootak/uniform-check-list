# 자치회 봉사 수첩 — 설치와 사용법

학생자치회 부원이 선 **아침 교통지도 · 점심 급식지도**를 날마다 입력하고,
학기마다 **봉사활동 시간을 자동으로 누계**하는 웹 앱입니다.
교복 지도 수첩과 같은 방식(구글 스프레드시트 + Apps Script)이라 준비물은 **구글 계정 하나**입니다.

**지금 설정: 선생님 한 분(강구탁)이 모두 담당합니다.**
앱 주소를 열면 **PIN 없이 바로** 입력 화면이 뜨고, 입력자는 언제나 `강구탁`, 화면은 **밝게** 고정됩니다.
학생은 앱을 쓰지 않습니다. 그러니 **앱 주소를 학생에게 알려주지 마세요.** 주소를 아는 사람은 누구나 입력할 수 있습니다.

> 나중에 여럿이 쓰게 되면 `설정` 시트의 세 칸만 비우면 됩니다. 코드는 고치지 않습니다. → 아래 [혼자쓰기 끄기](#혼자쓰기-끄기)

---

## 설치 (처음 한 번, 컴퓨터에서 15분)

1. 주소창에 `sheets.new` → 새 스프레드시트. 이름 예: `2026 자치회 봉사`
2. **확장 프로그램 → Apps Script**
3. `function myFunction() {}` 를 지우고 이 폴더의 **`Code.gs`** 내용을 붙여넣습니다.
4. 왼쪽 `파일` 옆 **＋ → HTML**, 이름을 **`Index`** 로 만들고 내용을 지운 뒤 **`Index.html`** 을 붙여넣습니다.
5. **Ctrl+S** 로 저장 → 스프레드시트 탭으로 돌아가 **새로고침(F5)**
6. 위쪽에 생긴 **`자치회 봉사` → ① 초기 설정** 을 누릅니다.
   처음에는 권한을 묻습니다. `고급 → (프로젝트)(으)로 이동 → 허용` 을 누르세요. 선생님이 만든 스크립트라 나오는 안내입니다.
7. `부원` · `순번` · `활동` · `설정` 시트가 생깁니다. **`설정`** 시트에서 아래를 채웁니다.

| 항목 | 예시 | 설명 |
|---|---|---|
| 혼자쓰기 | `예` (미리 들어가 있음) | PIN 없이 바로 들어옵니다 |
| 고정입력자 | `강구탁` (미리 들어가 있음) | 모든 기록의 입력자 이름 |
| 화면밝기 | `밝게` (미리 들어가 있음) | 휴대폰이 어두운 모드여도 밝은 화면 |
| 관리PIN | 비워 둠 | 혼자쓰기 동안에는 쓰지 않습니다 |
| 급식지도분 | `20` | 점심 급식지도 한 번에 인정하는 분 (아침 교통지도는 입력할 때마다 선생님이 넣습니다) |
| 학기시작 · 학기종료 | `2026-08-17` · `2027-02-12` | 비워두면 1학기 3/1~8/15, 2학기 8/16~2월 말 |
| 시간계산 | `내림` | `내림` · `반올림` · `그대로` (아래 참고) |

> 위 세 칸은 **이미 채워져 있어서 따로 할 일이 없습니다.** 학교명·학기 날짜만 원하시면 넣으세요.

8. Apps Script 탭에서 **배포 → 새 배포 → ⚙ 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
9. 나온 **웹 앱 URL** 이 앱 주소입니다. (나중에 `자치회 봉사 → ② 앱 주소 보기`)

> **코드를 고친 뒤에는** `배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포` 를 해야 반영됩니다. 주소는 그대로입니다.

## 처음 준비 (휴대폰이나 컴퓨터에서)

### 1. 부원 등록 — `관리` 탭
한 줄에 한 명씩 붙여넣고 **부원 명단에 반영**.

```
20301 김하늘 학습부
20415 이도현 총무부
10208,박서연,체육부
10101 최민준
```

학번·이름은 꼭, 부서는 있으면 넣습니다. 엑셀에서 열을 복사해 붙여넣거나 CSV 파일을 열어도 됩니다.
이미 있는 학번은 이름·부서만 바뀝니다.

### 2. (선택) 순번표 — `순번` 탭
꼭 하지 않아도 됩니다. 정해 두면 **입력** 화면에 그날 순번 학생이 버튼으로 떠서 드롭다운을 열지 않고 바로 고를 수 있습니다.

- **자동으로 나누기** — 활동 중인 부원을 월~금에 고르게 나눕니다.
  (`하루에 아침·점심 함께` / `아침·점심을 다른 요일에` / `아침 교통지도만` / `점심 급식지도만`)
- 나눈 뒤에도 칸마다 **고치기** 로 사람을 넣고 뺄 수 있습니다.
- 순번표를 바꿔도 **이미 입력한 기록은 그대로**입니다.

### 3. 휴대폰 홈 화면에 추가 (선택)
앱 주소를 선생님 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 씁니다.
(아이폰: 공유 → 홈 화면에 추가 / 안드로이드: ⋮ → 홈 화면에 추가)

> 부원 개인 조회 링크는 **혼자쓰기 동안 쓰지 않습니다.** 링크 안에 앱 주소가 들어 있어서, 학생이 링크 끝을 지우면 선생님 화면이 열리기 때문입니다.
> 학생이 자기 시간을 확인해야 하면 `누계` 탭의 표나 `누계` 시트를 보여 주세요.

---

## 매일 — `입력` 탭

1. **구분** — `아침 교통지도` / `점심 급식지도` (오전 11시 전에는 아침이 먼저 골라져 있습니다)
2. **학생** — 드롭다운에서 `학번 이름` 을 고릅니다. 관리 탭에 등록한 부원이 학번 순으로 나옵니다.
   이미 입력한 학생은 `✓ 30분` 처럼 표시됩니다. 순번표를 정해 두었다면 아래 **순번** 버튼으로도 고를 수 있습니다.
3. **봉사 시간(분)**
   - 점심 급식지도: **20분**이 미리 들어가 있습니다.
   - 아침 교통지도: 선생님이 그날 시간을 **5분 단위 드롭다운**(5분, 10분 … 2시간)에서 고릅니다.
     한 번 고른 시간은 **다음 학생에게도 그대로 남아**, 같은 시간 선 학생들은 학생만 바꿔 고르면 됩니다.
4. **입력** 을 누르면 아래 **입력 내역**에 바로 나타납니다.

- 같은 날 같은 구분에 같은 학생을 다시 입력하면 **새로 생기지 않고 시간이 고쳐집니다.** (`20분 → 15분으로 고쳤습니다`)
- 입력 내역의 **고치기** 로 시간·메모를 바꾸거나 기록을 지울 수 있습니다.
- 누가 입력했는지(입력자 이름)가 함께 남습니다. 처음 들어오면 이름을 묻습니다.
- 선생님은 `‹ ›` 와 `날짜` 로 지난 날을 열어 빠뜨린 것을 입력할 수 있습니다. (주말은 건너뜁니다)
- 활동 중단한 부원은 드롭다운에 나오지 않습니다.

---

## 학기 말 결재 — `누계` 탭

- 기간: **이번 학기** · 이번 달 · 전체 · 기간 지정
- 부원별 **교통지도 횟수 · 급식지도 횟수 · 총 시간 · 인정 시간** 이 나옵니다.
- **누계 시트로 내보내기** → 스프레드시트에 `누계` 시트가 새로 만들어집니다. 그대로 인쇄해 결재에 붙이세요.
  (스프레드시트 메뉴 `자치회 봉사 → 이번 학기 누계 시트 만들기` 로도 됩니다)
- **표 복사 (엑셀용)** → 엑셀·한글 표에 바로 붙여넣을 수 있습니다.
- 부원 이름을 누르면 날짜별 기록이 나오고, **고치기** 로 한 건의 시간(분)·메모를 바꾸거나 지울 수 있습니다.

### 인정 시간 계산 (`시간계산`)

| 값 | 5시간 50분일 때 | 5시간 30분일 때 |
|---|---|---|
| `내림` (기본) | 5시간 | 5시간 |
| `반올림` | 6시간 | 6시간 |
| `그대로` | 5.8시간 | 5.5시간 |

학교 봉사활동 인정 기준에 맞춰 고르세요. 학기 **합계**에 한 번 적용합니다. (하루하루 내림하지 않습니다)

## 자주 겪는 상황

**부원이 그만뒀어요**
`관리` 탭 → 부원 이름 → **활동 중단**. 입력 드롭다운과 순번표에서 빠지고, 이미 한 시간은 누계에 남습니다.
**명단에서 삭제** 를 해도 지난 기록은 지워지지 않습니다.

**입력자 이름을 바꾸고 싶어요**
`설정` 시트의 **고정입력자** 칸을 고치면 됩니다. (최대 30초 뒤 반영) 이미 입력한 기록의 입력자는 바뀌지 않습니다.

**어두운 화면으로 쓰고 싶어요**
`설정` 시트의 **화면밝기** 칸을 비우면 `내 설정` 에서 밝게/어둡게를 고를 수 있습니다.

### 혼자쓰기 끄기
여러 선생님이 쓰거나 학생에게 개인 조회 링크를 주고 싶을 때:
1. `설정` 시트에서 **관리PIN** 에 선생님만 아는 번호를 넣고
2. **혼자쓰기** 칸을 비웁니다. (고정입력자·화면밝기도 비우면 각자 이름을 넣고 밝기를 고릅니다)

그러면 앱이 관리PIN을 묻고, `관리` 탭에서 부원 개인 조회 링크도 만들 수 있습니다.
부원 링크로는 **자기 기록 보기만** 되고 입력·수정은 서버에서 막습니다.

**부원이 링크를 잃어버렸어요 / 휴대폰을 바꿨어요** (혼자쓰기를 껐을 때)
같은 링크를 다시 보내 주면 됩니다. 휴대폰을 잃어버렸다면 부원 이름 → **새 링크로 바꾸기** — 예전 링크는 더 이상 열리지 않습니다.

**점심 급식지도 시간을 바꾸고 싶어요**
`관리` 탭 → 봉사 시간 설정 → **점심 급식지도 1회 (분)**. 그다음 입력부터 새 시간이 미리 채워집니다.
이미 입력한 기록은 입력 내역·부원 화면에서 한 건씩 고치거나, `활동` 시트의 `인정분` 칸을 직접 고치세요.
그날만 다르면(단축 수업 등) 입력할 때 시간 칸만 바꿔 넣으면 됩니다.

**새 학기가 됐어요**
지울 것이 없습니다. `설정` 시트(또는 `관리` 탭)의 학기 날짜만 바꾸면 누계가 새 학기로 셉니다.
부원 명단과 순번표를 새로 맞추세요. 시작 전에 **백업 사본 만들기** 를 권합니다.

**스프레드시트를 직접 고쳐도 되나요**
됩니다. `활동` 시트는 한 줄이 한 번의 지도입니다. (`날짜` 는 `2026-10-21` 형식, `구분` 은 `아침 교통지도` / `점심 급식지도`, `인정분` 은 숫자)
고친 내용은 앱의 새로고침(오른쪽 위 ● 버튼) 뒤에 보입니다.

**다른 사람이 입력한 게 제 화면에 안 보여요**
약 20초마다 자동으로 받아옵니다. 급하면 오른쪽 위 ● 를 누르세요.

## 시트 구성

| 시트 | 열 |
|---|---|
| `부원` | 학번, 이름, 학년, 반, 번호, 부서, 상태(활동/중단), 개인코드, 메모 |
| `순번` | 요일, 구분, 학번, 이름 — 한 칸에 한 사람씩 |
| `활동` | 기록ID, 날짜, 구분, 학번, 이름, 인정분, 입력자, 입력일시, 메모 |
| `설정` | 관리PIN, 학교명, 급식지도분, 학기시작, 학기종료, 혼자쓰기, 고정입력자, 화면밝기, 시간계산 |
| `누계` | 내보내기를 누를 때마다 새로 씀 (결재용) |

## 개인정보

- 학번·이름·활동 기록은 **선생님의 구글 드라이브**에만 저장됩니다.
- 혼자쓰기 동안에는 **앱 주소가 곧 열쇠**입니다. 주소를 공유하지 마세요.
- 혼자쓰기를 끄고 부원 링크를 쓰면, 링크로는 **자기 기록만** 보이며 서버에서도 다른 사람 자료를 내주지 않습니다.
- 학년이 바뀌면 지난 자료는 백업 사본으로 남긴 뒤 정리하시길 권합니다.
