# 자치회 봉사 수첩 — 설치와 사용법

학생자치회 부원이 순번대로 서는 **아침 교통지도 · 점심 급식지도**를 휴대폰으로 확인하고,
학기마다 **봉사활동 시간을 자동으로 누계**하는 웹 앱입니다.
교복 지도 수첩과 같은 방식(구글 스프레드시트 + Apps Script)이라 준비물은 **구글 계정 하나**입니다.

| 누가 | 들어오는 방법 | 할 수 있는 일 |
|---|---|---|
| 담당 선생님 | 앱 주소 + **관리 PIN** | 모든 날짜의 참여·불참 표시와 수정, 순번표, 부원 관리, 누계, 설정 |
| 회장단 (지도 확인 담당) | 앱 주소 + **기록 PIN** | **오늘** 순번의 참여·불참 표시, 순번표 보기 |
| 부원 본인 | 선생님께 받은 **개인 링크** (PIN 없음) | 자기 봉사시간·순번·기록 보기만 |

---

## 설치 (처음 한 번, 컴퓨터에서 15분)

1. 주소창에 `sheets.new` → 새 스프레드시트. 이름 예: `2026 자치회 봉사`
2. **확장 프로그램 → Apps Script**
3. `function myFunction() {}` 를 지우고 이 폴더의 **`Code.gs`** 내용을 붙여넣습니다.
4. 왼쪽 `파일` 옆 **＋ → HTML**, 이름을 **`Index`** 로 만들고 내용을 지운 뒤 **`Index.html`** 을 붙여넣습니다.
5. **Ctrl+S** 로 저장 → 스프레드시트 탭으로 돌아가 **새로고침(F5)**
6. 위쪽에 생긴 **`자치회 봉사` → ① 초기 설정** 을 누릅니다.
   처음에는 권한을 묻습니다. `고급 → (프로젝트)(으)로 이동 → 허용` 을 누르세요. 선생님이 만든 스크립트라 나오는 안내입니다.
7. `부원` · `순번` · `활동` · `설정` 시트가 생깁니다. **`설정`** 시트에서 아래를 채웁니다.

| 항목 | 예시 | 설명 |
|---|---|---|
| 기록PIN | `2026` | 회장단용 |
| 관리PIN | `7788` | 선생님용 (기록PIN과 다르게) |
| 교통지도분 | `30` | 아침 교통지도 한 번에 인정하는 분 |
| 급식지도분 | `30` | 점심 급식지도 한 번에 인정하는 분 |
| 학기시작 · 학기종료 | `2026-08-17` · `2027-02-12` | 비워두면 1학기 3/1~8/15, 2학기 8/16~2월 말 |
| 시간계산 | `내림` | `내림` · `반올림` · `그대로` (아래 참고) |

> 두 PIN을 모두 비워두면 **주소를 아는 누구나 관리자로** 들어옵니다. 꼭 채워 주세요.

8. Apps Script 탭에서 **배포 → 새 배포 → ⚙ 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
9. 나온 **웹 앱 URL** 이 앱 주소입니다. (나중에 `자치회 봉사 → ② 앱 주소 보기`)

> **코드를 고친 뒤에는** `배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포` 를 해야 반영됩니다. 주소는 그대로입니다.

## 처음 준비 (휴대폰이나 컴퓨터에서, 관리 PIN으로)

### 1. 부원 등록 — `관리` 탭
한 줄에 한 명씩 붙여넣고 **부원 명단에 반영**.

```
20301 김하늘 학습부
20415 이도현 총무부
10208,박서연,체육부
10101 최민준
```

학번·이름은 꼭, 부서는 있으면 넣습니다. 엑셀에서 열을 복사해 붙여넣거나 CSV 파일을 열어도 됩니다.
이미 있는 학번은 이름·부서만 바뀝니다.

### 2. 순번표 — `순번` 탭
- **자동으로 나누기** 를 누르면 활동 중인 부원을 월~금에 고르게 나눕니다.
  - `하루에 아침·점심 함께` — 부원마다 한 요일, 그날 두 번 다 섬
  - `아침·점심을 다른 요일에` — 아침 하루, 점심 하루를 다른 요일에
  - `아침 교통지도만` / `점심 급식지도만`
- 나눈 뒤에도 칸마다 **고치기** 로 사람을 넣고 뺄 수 있습니다.
- 아래 **순번이 없는 부원** 에서 빠진 사람이 없는지 확인하세요.
- 순번표를 바꿔도 **이미 남긴 기록은 그대로**입니다.

### 3. 회장단과 부원에게 나눠주기
- 회장단: **앱 주소 + 기록 PIN**
- 부원: `관리` 탭 → **링크 없는 부원 모두 만들기** → **이름·링크 목록 복사** 로 각자에게 보냅니다.
  부원은 링크를 열고 **홈 화면에 추가**하면 끝입니다. 자기 기록만 보이고 다른 부원 것은 보이지 않습니다.

## 매일 — `오늘` 탭

오늘 요일의 **아침 교통지도 / 점심 급식지도** 순번이 그대로 뜹니다.

- 선 사람은 **참여**, 오지 않은 사람은 **불참**. 잘못 눌렀으면 **같은 버튼을 한 번 더** 누르면 지워집니다.
- **남은 n명 참여** — 아직 표시하지 않은 순번을 한 번에 참여로.
- **＋ 부원 추가** — 순번이 아닌 부원이 대신 섰을 때. 참여로 기록되고 `순번 외` 표시가 붙습니다.
- 같은 날 같은 시간에는 한 사람에 **한 줄만** 남습니다. 두 사람이 동시에 눌러도 겹치지 않습니다.
- 누가 확인했는지(확인자 이름)가 함께 남습니다. 처음 들어오면 이름을 묻습니다.
- 회장단(기록 PIN)은 **오늘만** 표시할 수 있습니다. 지난 날짜를 고치는 것은 선생님만 합니다.
- 선생님은 `‹ ›` 와 `날짜` 로 지난 날을 열어 빠진 표시를 채울 수 있습니다. (주말은 건너뜁니다)

---

## 학기 말 결재 — `누계` 탭 (관리 PIN)

- 기간: **이번 학기** · 이번 달 · 전체 · 기간 지정
- 부원별 **교통지도 횟수 · 급식지도 횟수 · 불참 · 총 시간 · 인정 시간** 이 나옵니다.
- **누계 시트로 내보내기** → 스프레드시트에 `누계` 시트가 새로 만들어집니다. 그대로 인쇄해 결재에 붙이세요.
  (스프레드시트 메뉴 `자치회 봉사 → 이번 학기 누계 시트 만들기` 로도 됩니다)
- **표 복사 (엑셀용)** → 엑셀·한글 표에 바로 붙여넣을 수 있습니다.
- 부원 이름을 누르면 날짜별 기록이 나오고, **고치기** 로 한 건의 인정 시간(분)·메모를 바꾸거나 지울 수 있습니다.
  (시험 기간이라 짧게 섰다든지 하는 경우)

### 인정 시간 계산 (`시간계산`)

| 값 | 5시간 50분일 때 | 5시간 30분일 때 |
|---|---|---|
| `내림` (기본) | 5시간 | 5시간 |
| `반올림` | 6시간 | 6시간 |
| `그대로` | 5.8시간 | 5.5시간 |

학교 봉사활동 인정 기준에 맞춰 고르세요. 학기 **합계**에 한 번 적용합니다. (하루하루 내림하지 않습니다)

## 자주 겪는 상황

**부원이 그만뒀어요**
`관리` 탭 → 부원 이름 → **활동 중단**. 순번표와 추가 목록에서 빠지고, 이미 한 시간은 누계에 남습니다.
**명단에서 삭제** 를 해도 지난 기록은 지워지지 않습니다.

**부원이 링크를 잃어버렸어요 / 휴대폰을 바꿨어요**
같은 링크를 다시 보내 주면 됩니다. 휴대폰을 잃어버렸다면 부원 이름 → **새 링크로 바꾸기** — 예전 링크는 더 이상 열리지 않습니다.

**인정 시간(분)을 바꿨는데 예전 기록은 그대로예요**
설정은 **그다음 기록부터** 적용됩니다. 지난 기록은 부원 화면에서 한 건씩 고치거나, `활동` 시트의 `인정분` 칸을 직접 고치세요.

**새 학기가 됐어요**
지울 것이 없습니다. `설정` 시트(또는 `관리` 탭)의 학기 날짜만 바꾸면 누계가 새 학기로 셉니다.
학년이 바뀌면 PIN을 바꾸고, 부원 명단과 순번표를 새로 맞추세요. 시작 전에 **백업 사본 만들기** 를 권합니다.

**스프레드시트를 직접 고쳐도 되나요**
됩니다. `활동` 시트는 한 줄이 한 번의 지도입니다. (`날짜` 는 `2026-10-21` 형식, `구분` 은 `아침 교통지도` / `점심 급식지도`, `상태` 는 `참여` / `불참`)
고친 내용은 앱의 새로고침(오른쪽 위 ● 버튼) 뒤에 보입니다.

**다른 사람이 표시한 게 제 화면에 안 보여요**
약 20초마다 자동으로 받아옵니다. 급하면 오른쪽 위 ● 를 누르세요.

## 시트 구성

| 시트 | 열 |
|---|---|
| `부원` | 학번, 이름, 학년, 반, 번호, 부서, 상태(활동/중단), 개인코드, 메모 |
| `순번` | 요일, 구분, 학번, 이름 — 한 칸에 한 사람씩 |
| `활동` | 기록ID, 날짜, 구분, 학번, 이름, 인정분, 상태, 확인자, 기록일시, 메모 |
| `설정` | 기록PIN, 관리PIN, 학교명, 교통지도분, 급식지도분, 학기시작, 학기종료, 시간계산 |
| `누계` | 내보내기를 누를 때마다 새로 씀 (결재용) |

## 개인정보

- 학번·이름·활동 기록은 **선생님의 구글 드라이브**에만 저장됩니다.
- 부원 링크로는 **자기 기록만** 보이며, 서버에서도 다른 사람 자료를 내주지 않습니다.
- 학년이 바뀌면 PIN을 바꾸고, 지난 자료는 백업 사본으로 남긴 뒤 정리하시길 권합니다.
